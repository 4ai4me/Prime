# 이하연 수학 교실 — 중1 「Ⅰ. 소인수분해」 탐구 프로젝트 (Prime)

중학교 1학년 소인수분해 단원 수업을 위한 **학생·교사 승인제 탐구 활동지 사이트**입니다.
고등학교 함수 단원 사이트 [`4ai4me/Func`](https://4ai4me.github.io/Func/)와 같은 구조(가입 승인, 클라우드 자동 저장, 차시 잠금, 교사 기록실)를 그대로 옮겨 왔고, 학생 답안과 잠금 설정은 Prime 전용 칸에 따로 저장합니다.

- 주소: `https://4ai4me.github.io/Prime/` (GitHub Pages 설정 후)
- 현재 상태: **1~4차시 완성** (2026-11-23). 5·6차시는 "활동지 준비 중" 화면이며, 교과서 자료를 받는 대로 한 차시씩 채웁니다.

### 1차시 「소수란 무엇일까?」 (`src/lessons/Lesson1View.tsx`, 채점 `lesson1Logic.ts`, 타일 놀이판 `TileBoard.tsx`) — 7단계

| 단계 | 내용 | 완료 조건 |
|---|---|---|
| 1. 단원 열기 · 준비 학습 | 지구가 더워지는 이유(원자 결합 → 6 = □ × □, 결합된 예 서술) · 초5~6 준비 학습 8문항(약수·배수·최대공약수·최소공배수) + 자기 점검 | 두 [점검] 통과 |
| 2. 생각 열기 · 약수 모여라 | 숫자 카드로 6의 약수·7의 약수 고르기, 7처럼 약수가 1과 자기 자신뿐인 수 3개 이상 쓰기 | [점검] 통과 |
| 3. 소수와 합성수의 뜻 | 개념(素數·合成數, 小數와 구분), 보기 13·15, 생각 톡톡(소수의 약수 개수), 1의 분류(맞히면 자연수 = 1·소수·합성수 그림), 내가 고른 수(2~100) 판별 | 두 [점검] 통과 |
| 4. 문제 1 · 소수? 합성수? | 11·14·19·27 판별 + 합성수로 고른 수는 1과 자기 자신이 아닌 약수(증거), 오개념 점검 "2는 짝수니까 소수가 아니야?" + 이유 | 두 [점검] 통과 |
| 5. 도형 · 타일 배열 (2026-11-13 추가) | 정사각형 타일 6개 → 1×6, 2×3 예시 그림 / 활동 1: 타일 7개 / 활동 2: 타일 16개 — 한 줄에 놓을 개수를 정해 늘어놓고 직사각형이 되면 기록(돌린 모양은 한 가지), 방법 수 쓰기 / 활동 3: 자유 놀이판으로 실험해 방법이 한 가지뿐인 개수 3개 이상 + 특징 서술 | 세 [점검] 통과 |
| 6. 도전 · 수준별 문제 | 2~10에서 5개를 골라 약수의 합이 8 더 크게(카드 5개까지, 합·차이 바로 표시) + 방법 설명 20자 이상 (답 2, 3, 5, 7, 9 — 유일) | [점검] 통과 |
| 7. 성찰 | 공용 성찰(성찰 1·2 + 도움 받은 정도) | 성찰 1 20자 이상 |

- [점검]은 틀린 문항만 알려 주고 정답은 보여 주지 않습니다. 맞힌 뒤 답을 고치면 그 문항의 ✓가 지워져 다시 점검합니다.
- 교과서 그림 대신 숫자 카드 등 직접 누르는 활동으로 만들었습니다(이미지 파일 없음).
- 2차시용 자료(에라토스테네스의 체, 문제 2, 배운 내용 확인하기, 수학 이야기)는 2차시에 씁니다.

### 2차시 「소수를 어떻게 찾을 수 있을까?」 (`Lesson2View.tsx`, 채점 `lesson2Logic.ts`) — 5단계

| 단계 | 내용 |
|---|---|
| 1. 함께하기 · 에라토스테네스의 체 | 1~50 수 판에서 안내대로 1 지우기 → 처음 남은 수에 ○ → [배수 지우기] 반복(순서를 어기면 까닭 안내), 7 다음부터 [남은 수에 모두 ○표] / 질문: 2의 배수를 지우는 이유, 50까지의 소수 쓰기, 몇의 배수까지 지우면 충분한지(7) |
| 2. 문제 2 · 51부터 100까지 | 51~100 판에서 소수 고르기 — 아닌 수와 빠진 개수만 안내(정답 비공개) |
| 3. 배운 내용 확인하기 | 개념 빈칸, 1번 ○△(1, 12, 23, 41, 57, 74), 2번 OX 4문항, 3번 훈민정음 글의 밑줄 친 수 눌러 고르기 |
| 4. 수학 이야기 · 더 큰 소수 | 큰 소수 이야기(요약) + 2를 n번 곱한 수에서 1을 뺀 수(n = 2~7) 소수·합성수 판단 |
| 5. 성찰 | 공용 성찰 |

- 교과서의 신나는 놀이 & 수학 '어떻게 색칠하면 될까?'는 자료를 받으면 단계로 추가합니다.

### 4차시 「소인수분해는 어떻게 할까?」 (`Lesson4View.tsx`, 채점 `lesson4Logic.ts`, 소인수 나무·나눗셈 `SplitBuilder.tsx`) — 7단계

| 단계 | 내용 |
|---|---|
| 1. 생각 열기 · 소인수 | 12 = 2 × □, 3 × □, 12의 약수와 그중 소수 → 소인수의 뜻(약수 = 인수) / 문제 2 (16, 33, 42, 80의 소인수) |
| 2. 소인수분해 · 함께하기 | 소인수분해의 뜻, 소수 버튼을 눌러 키우는 소인수 나무로 24를 [순서 1] 2부터·[순서 2] 3부터 → 결과 비교(한 가지뿐) |
| 3. 예제 1 · 문제 3 | 90을 곱셈식·가지·나눗셈(직접 하는 사다리)으로, 32·63·98·150 소인수분해 |
| 4. 소인수분해로 약수 구하기 | 예제 2 (75 표 채우기), 생각 톡톡(6과 9), 문제 4 (2² × 5², 54), 도전(상) 40의 약수 개수 |
| 5. 교구 & 공학 도구 · 블록 코딩 | 프로그램 순서 설명, 엔트리 작품 새 창 열기(`curriculum.ts`의 `BLOCK_CODING_URL`), 활동 1 (5239) · 활동 2 (내가 고른 수) 결과 입력 |
| 6. 배운 내용 확인하기 | 개념 빈칸, 소인수 구하기, 소인수분해 하기, 108의 약수 고르기, 서술형 28 × □ (답 7, 풀이) |
| 7. 성찰 | 공용 성찰 |

- 거듭제곱 답은 2⁵, 2^5, 2 ^ 5 모두 읽습니다(`powerExpr.ts`). 소인수분해 답은 소수만, 같은 소인수는 거듭제곱으로 묶어서, 작은 소인수부터 써야 정답입니다.
- 수학 기호 입력기에 ⁵·⁶과 키보드 단축어 ^5·^6·^7을 추가했습니다.

## 2. 주요 기능 (Func와 같음)

- **학생 가입·로그인**: 가상 정보(랜덤 이름·학년·새 이름 반)와 비밀번호로 가입 신청 → 선생님이 교실에서 확인 후 승인. 가입 정보는 Func·Props·Rational와 함께 씁니다. 아래 '학생 가상 정보 가입' 참고.

**학생 가상 정보 가입 (2026-11-28~, Func·Props·Prime·Rational 공통)**
- 실명·학번·생년월일을 받지 않습니다. 학생은 **학교 "하연 학교"(고정) · 년도(가입한 날, 한국 시간, 고정) · 랜덤 한글 이름(2~4자, 버튼으로만 만듦) · 학년(중1~고3) · 교사가 만든 새 이름 반 · 비밀번호(필수, 재확인)**로 가입 신청하고, 교사가 교실에서 얼굴과 화면을 확인한 뒤 승인합니다. 실제 학생과 가상 이름의 대응은 교사가 오프라인으로만 관리합니다.
- 가입 문서 키는 `v2_{이름}`입니다. 같은 이름은 같은 문서라서 서버가 중복 가입을 막습니다. 문서 표시 `schema: 2`.
- 로그인: 이름 + 비밀번호. 다른 기기에서 로그인하면 보안 규칙이 비밀번호 해시를 확인한 뒤 그 기기로 연결합니다(앞 기기는 연결 해제).
- 비밀번호는 항상 필수입니다(켜고 끄는 설정 없음). 원문은 저장하지 않고 `SHA-256(접두어|학생키|비밀번호)` 해시만 저장합니다. 조건(8~32자, 대·소문자·숫자·특수문자) 검사는 학생 화면에서만 합니다(서버는 해시만 받음).
- **비밀번호 분실**: 교사가 [학생 가입 관리] 표의 **[코드 발급]** → 8자리 일회용 코드(예: `ABCD-EFGH`)가 한 번만 보임 → 학생이 [비밀번호 재설정]에서 이름·코드·새 비밀번호 입력. 코드는 30분 안에 한 번만 쓸 수 있고, 원문은 저장하지 않습니다(`resetCodeHash`). 코드를 쓰기 전까지 기존 비밀번호는 그대로 쓸 수 있습니다.
- **새 이름 반**: 교사가 [새 이름 반 만들기]에서 년도를 고르고 학년마다 반 개수를 넣으면 새 이름 반(예: 참새반)이 랜덤으로 만들어집니다(`app_settings/class_roster_{년도}`). 같은 년도 안에서는 겹치지 않고, 년도가 다르면 같은 이름이어도 다른 반입니다. 학생이 가입한 반은 다시 만들어도 남습니다. 학생은 **가입한 날의 년도** 반 중에서만 고를 수 있고, 보안 규칙도 그 목록에 있는 반인지 확인합니다. (1~2월에 가입하는 학생은 새 년도 반이 필요합니다)
- 반별 차시 잠금의 반 키는 `년도|학년|반이름`(예: `2026|중1|참새반`)입니다.
- **예전 방식 가입 정보**: 2026-11-28 이전 문서로는 어떤 경로로도 입장할 수 없습니다(보안 규칙이 학생의 읽기·쓰기·재연결을 모두 거부, 기기에 남은 예전 로그인 정보는 `main.tsx`에서 지움). 교사 화면의 **[예전 개인정보 모두 삭제]**(1회, 백업 없음)는 예전 학생의 실명·학교·반·번호·생년월일과 기기 잠금·예전 접속 기록·예전 반별 잠금을 지우고, 활동지는 무작위 번호(`이전기록-001`, 문서 키 `legacy_001`)와 학년만 붙여 남깁니다. 이 기록은 교사 화면 **[이전 기록]**에서 **2027-03-31까지** 읽기 전용으로 볼 수 있습니다.
- 학생 삭제는 가입 문서와 네 사이트의 차시 문서를 함께 지웁니다(이름이 풀려 다른 학생이 받을 수 있게 되므로).
- 관련 코드(네 저장소에서 똑같아야 함): `src/utils/studentIdentity.ts`(이름·반·코드·기기 정리, 단위 테스트), `src/utils/studentAccount.ts`, `src/utils/legacyCleanup.ts`, `src/components/StudentPortal.tsx`, `src/components/StudentRegistrationPanel.tsx`, `src/components/LegacyRecordsPanel.tsx`, `firestore.rules`.

- **자동 저장**: 입력을 멈추고 10초 뒤, 단계·차시 이동, 탭 전환·닫기 때 바뀐 차시만 저장. [지금 저장] 버튼.
- **차시 잠금**: 교사가 1~6차시를 전체 또는 **반별로** 열고 잠급니다. 학생 화면에 새로고침 없이 바로 반영되고, 주소(`?lesson=5`) 직접 입력으로도 잠긴 차시에 들어갈 수 없습니다.
- **학생 화면**: 중단원별로 묶은 차시 탭, 진행 현황, 「평가 결과」 창(선생님 점수·피드백), 수학 기호 입력기(×, ², ³ 등 중1용으로 줄임).
- **교사 기록실**: 차시 잠금, 가입 승인·반려·삭제·비밀번호 초기화, 실시간 접속 기록, 학생별 1~6차시 진행 표, [답안 · 평가](차시별 답안 + 0~3점 평정 + 피드백 + 저장 버튼), 평가서 인쇄, CSV 내려받기.

```
    ReflectionStep.tsx       공용 성찰 단계 (서술 2칸 + 도움 받은 정도)
    answerLabels.ts          교사 화면·CSV 문항 이름표
  components/                Func에서 가져온 화면 부품 + 교사 화면(TeacherView)
  utils/
    lessonAccess.ts          차시 잠금 계산
    classLessonAccess.ts     반별 잠금
    studentRecord.ts         학생 기록 형식·교사 평가
    lessonStore.ts           Firebase 저장·불러오기
    teacherRecords.ts        교사 표·CSV 계산
```

차시 자료를 채우는 순서는 `AGENTS.md`의 「차시 자료 채우는 순서」를 봅니다.

## 5. 개발

```bash
bun install                 # 또는 npm install
npm run dev                 # 개발 서버
npx tsc --noEmit            # 타입 검사
npx tsx --test src/**/*.test.ts src/**/*.test.tsx   # 단위 테스트
npm run build               # 배포 파일(ghpages-app.js·css) 갱신
```

GitHub Pages는 `index.html` + `ghpages-app.js` + `ghpages-app.css`를 그대로 보여 줍니다. 화면을 바꿔 배포할 때마다 `index.html`의 `?v=` 값을 바꿉니다.
